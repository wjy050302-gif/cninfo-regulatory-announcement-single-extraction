# Submission Checklist Folder

This folder is a convenience index for what to submit.

- It does **not** include `.env` (secrets). Only `.env.example` is referenced.
- Large datasets (`data/pdf/`, `data/parsed/`) are **not duplicated** here to avoid a huge copy.
  - See `manifest.csv` for the canonical paths inside `final_repo/`.

Recommended submission method:
- Zip and submit the whole `final_repo/` directory **after deleting** `final_repo/.env`.
